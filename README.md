# HER PITCH — 여자축구 인생 시뮬레이션 (Beta 0.1)

## 실행
- `index.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 열면 바로 실행됩니다.
- 별도 설치나 서버가 필요 없는 정적 웹앱입니다.

## 공개 배포
1. GitHub 계정을 만들고 새 저장소(repository)를 생성합니다.
2. `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages → Deploy from a branch → `main` / `/(root)`를 선택하고 저장합니다.
4. 잠시 후 생성된 `https://계정명.github.io/저장소명/` 주소를 다른 사람과 공유할 수 있습니다.

또는 Netlify / Vercel에 이 폴더를 정적 사이트로 배포할 수 있습니다.

## 현재 베타 범위
- 선수 생성, 포지션/성장 경로 선택
- 훈련·팀 적응·연습경기·첫 공식 경기·시즌 평가의 선택형 진행
- 기본 능력치, 감독 신뢰도, 팀 유대감, 사기, 부상 위험, 경기 기록
- 반응형 모바일/PC UI

## 다음 개발 단계
현재 버전은 초기 플레이 테스트용 프로토타입입니다. 실제 장기 커리어 게임으로 확장하려면 연령별 유스 리그 구조, 국가별 리그/이적 규정, 시즌 일정·스탯 엔진, 국가대표 대회, FA/연봉 협상, 클라우드 저장 및 계정 시스템, 관리자용 콘텐츠 관리가 추가되어야 합니다.
